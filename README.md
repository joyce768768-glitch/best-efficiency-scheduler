# Best Efficiency Scheduler · 个人 Agent 工作台

AI-native 个人工作方式的自用系统：以「任务卡片先行，执行在后」为核心范式的任务调度中心。

## 核心机制

- **任务卡片先行**：先定义任务卡（目标 + 拆解 + 提示词），再由执行 Agent 实现
- **30s 轮询调度**：定时扫描任务队列，自动触发执行
- **7×24 运行**：配合系统级防休眠（pmset/caffeinate）实现全天候自动执行
- **多 Agent 工具矩阵**：统一调度多工具、多模型工作流

## 结构

`server.js / engine.js`（调度引擎）· `public/`（管理界面）· `scripts/`（运维脚本）

## 定位

这不是 demo——是作者日常驱动十余个 AI 项目交付的生产系统，AI-native 工作流的实证。
